# TP 3 PHP : Suivi des notes des apprenants

Auteur : Sekri Marouan, 18/10/2026


## Lancer l'application

```
cd tp_php
php -S localhost:8000
```

Puis ouvrir `http://localhost:8000/exo1_bases.php` (ou `saisie.html`, `login.php`...).

## Contenu

| Fichier | Partie du TP |
|---|---|
| `config.php` | constantes (`const`, `define`) et fonction `mention()` |
| `exo1_bases.php` | Parties 0 et 1 : variables, constantes, types, chaînes |
| `exo2_flux.php` | Partie 2 : if, switch, boucles |
| `exo3_tableaux.php` | Partie 3 et exercice 4.1 : tableaux, includes |
| `includes/` | entête, menu, pied de page (date et jours restants) |
| `info.html`, `info.php` | exercice 4.2 : formulaire GET |
| `saisie.html`, `traitement.php` | exercices 4.3 et 5.1 : formulaire POST et écriture CSV |
| `liste.php` | exercices 5.2 et 5.3 : lecture CSV |
| `export.php` | exercice 5.4 : JSON et serialize |
| `login.php`, `profil.php`, `deconnexion.php` | exercices 6.1, 6.2 et 6.3 : sessions, cookies, dates |
| `data/` | `notes.csv` et `notes.json` créés par les scripts |
